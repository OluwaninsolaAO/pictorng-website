# Monolith Technologies Limited brand assets

| File | Use |
| --- | --- |
| `logo-full-light.*` | Name lockup, dark text, transparent. For light backgrounds. |
| `logo-full-dark.*` | Name lockup, white text, transparent. For dark backgrounds. |
| `logo-full-light-bg.*` / `logo-full-dark-bg.*` | Same lockups on a solid white / near-black background. |
| `logo-mark.*` | Mark only, transparent. |
| `logo-mark-tile.*` | Mark on a rounded near-black tile. Profile pictures, app icons. |
| `apple-touch-icon.png`, `icon-512.png` | Tile at fixed sizes. |

Text in the SVG lockups is converted to outlines (Geist), so they render identically everywhere.
Colours: indigo `#6366F1`, light `#C4C6FF`, deep `#312E81`, ink `#07070B`.
